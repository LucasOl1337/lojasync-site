# Vitrine e tutorial do LojaSync

[Conhecer o projeto](https://lucasol1337.github.io/lojasync-site/) · [Aprender a usar](https://lucasol1337.github.io/lojasync-site/tutorial.html)

Página de apresentação, demonstração curta e guia de uso em vídeo, do primeiro acesso às rotinas da loja. O tutorial oferece capítulos em sequência, busca por recurso, legendas em português, transcrição, retomada e um romaneio fictício para treinamento.

Este repositório contém apenas páginas estáticas e mídias públicas. O aplicativo e sua documentação operacional permanecem no repositório privado da equipe.

As gravações mostram o aplicativo real em instalações de treinamento, com produtos, clientes, documentos e valores fictícios. Etapas dependentes de Windows, Byte Empresa, IA ou serviços externos são identificadas nas aulas; controles indisponíveis e falhas observadas não são apresentados como operações concluídas.

Publicação: GitHub Pages, branch `main`, diretório `/docs`.
