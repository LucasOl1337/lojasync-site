# Vitrine do LojaSync

Página de apresentação e demonstração do fluxo local de preparação de produtos para o Byte Empresa.

Este repositório contém somente a página estática e as mídias públicas de divulgação. O código do aplicativo e sua documentação operacional permanecem no repositório privado da equipe.

As capturas e o vídeo mostram o aplicativo real com produtos, documento e valores fictícios. A demonstração usa leitura local e não executa cadastros no Byte Empresa.

Publicação: GitHub Pages, branch `main`, diretório `/docs`.
